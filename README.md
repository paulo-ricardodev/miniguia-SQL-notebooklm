# miniguia-SQL-notebookLM
um guia do básico ao avançado de SQL feito no notebookLM

Esse guia foi modelado de forma que se passe por um curso de SQL, desde o introdutório, para quem nunca viu nada e nem sequer sabe do que se trata, até o avançado.
Tenho como objetivo completar lacunas de cursos que já vi sobre o assunto e também me aprofundar mais, podendo testar meus conhecimentos durante os estudos.
